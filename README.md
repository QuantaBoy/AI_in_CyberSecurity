# AI in CyberSecurity — CloudGuard Sentinel

An enterprise-grade Security Operations Center (SOC) dashboard utilizing Explainable AI (XAI) and Machine Learning (Isolation Forest) to detect, classify, and mitigate authentication anomalies.

## Tech Stack
*   **Frontend**: React + TypeScript + Vite + Tailwind CSS
*   **ML Engine**: Isolation Forest + Random Forest
*   **Database & Auth**: Supabase

## Setup & Run
1. Install dependencies: `npm install`
2. Launch dev server: `npm run dev`
3. Build for production: `npm run build`
